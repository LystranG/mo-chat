# Phase 1 8.3 Lifecycle HTTP Integration Tests Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为 `single-node-cloud-native-im-phase1` 的 8.3 补齐好友/群组生命周期 HTTP 集成测试，并在每批完成后更新 OpenSpec tasks 与定向测试结果。

**Architecture:** 采用 `MicronautTest + Embedded HTTP Client + PostgreSQL Testcontainers` 跑真实 controller/service/JDBC repository 闭环；通过测试内 Bean 替换提供可控 `RedisCommands`/`IdGenerator`，避免依赖真实 Redis/RocketMQ。优先覆盖好友请求收发/处理/拉黑解封，以及群组创建/申请加入/审核/踢人/解散等关键生命周期，必要时仅补最小生产代码修复集成缺口。

**Tech Stack:** Micronaut 4, Java 25, JUnit 5, Testcontainers PostgreSQL, Flyway, Mockito, OpenSpec Markdown tasks
