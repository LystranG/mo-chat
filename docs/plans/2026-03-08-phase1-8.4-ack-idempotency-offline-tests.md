# Phase 1 8.4 ACK Idempotency Offline Tests Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为 `single-node-cloud-native-im-phase1` 的 8.4 补齐 sender ACK 映射、幂等重复提交、离线队列与登录重放的集成测试，并在通过后更新 OpenSpec tasks。

**Architecture:** 采用两段式测试策略：第一段复用 `InboundMessageConsumerLifecycleTest` 的 `ApplicationContext + RecordingEventBus` 基座，覆盖 inbound message -> ACK -> idempotency -> offline enqueue 的消息入口闭环；第二段新增/扩展 `AuthController` HTTP 集成测试，使用真实 `OfflineReplayService` + 记录型 `OfflineQueue/EventBus`，覆盖登录触发离线消息重放。优先只补测试与测试替身；若红测暴露真实缺口，仅做与 8.4 直接相关的最小修复。

**Tech Stack:** Micronaut 4, Java 25, JUnit 5, Micronaut HTTP Client, ApplicationContext test beans, Mockito, OpenSpec tasks
